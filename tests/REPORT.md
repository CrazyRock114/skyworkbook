## 五、明确不测什么（范围声明）

- 后端/网络/并发：纯静态本地站，无服务端逻辑；
- 无障碍专项（读屏/键盘导航）：本轮未覆盖，列为后续工作；
- 教学内容的事实正确性全量复核：静态套件以"选项-解析交叉验证 + 出处格式"兜底，事实层依赖此前逐题人工审查（见两册答案文档），本轮未重复全量验 PDF；
- 浏览器兼容性矩阵：仅 Chrome/WebKit 内核（本机）验证。

## 六、残余风险声明

1. 期末卷答案键分布偏 B（63%）：已人工抽样+交叉验证判定为真实分布；学生长期刷题可能产生"猜 B"策略，建议后续改卷时混洗选项（低优先级）。
2. 无障碍与键盘可操作性未系统测试。
3. 极速60秒的自然到时终局（60 秒真实等待）由 `_test` 钩子直达终局验证，未做真实时长挂机（计时器逻辑为纯 setInterval 减法，风险低）。
4. data.js 与两个 JSON 的同步靠生成脚本保障，静态套件含抽查断言（首条 + 数量），非全量哈希。
